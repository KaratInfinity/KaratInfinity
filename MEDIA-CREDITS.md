## Hosting

The exact video file URLs were discovered in public embeds or the [Mixkit URL index](https://huggingface.co/datasets/HappyPockets/mixkit); subjects and Mixkit reuse availability were cross-checked on the source pages above. No guessed MP4 variants are used. Sources can change independently of this project. Production teams can replace these with their own licensed, optimized media using `lib/module-media.ts`; see README.md.

The code keeps each photograph visible while video loads, on error, when autoplay is blocked, or when motion/data preferences require a still. No third-party player script is loaded.
